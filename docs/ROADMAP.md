# ROADMAP — «до уровня StockX» (навигация + оформление карточек)

> Выполняем фаза за фазой: пользователь говорит «делай фазу N» — Claude делает
> ровно одну фазу, проверяет, коммитит, обновляет STATUS. Порядок продуман по
> зависимостям: роутинг — фундамент, без него остальное не имеет смысла.

## Как устроен StockX (эталон)

**Глобальный хедер:** логотип · ПОИСК ПО ЦЕНТРУ (доступен с любой страницы,
с живыми подсказками) · категории (Sneakers / Apparel / Accessories / Brands) ·
иконки (избранное/профиль). Под хедером — строка трендовых запросов.

**Главная:** hero-промо → горизонтальные ряды-карусели («Trending», «New Lowest
Asks», «Most Popular», категорийные), каждый ряд с «See All →» на каталог с
фильтром. Плитки брендов/коллекций.

**Каталог (browse):** хлебные крошки · левый сайдбар фильтров (категории-дерево,
бренд, размер, цена…) · сортировка + счётчик · пагинация. На мобиле фильтры —
bottom sheet.

**Страница товара (PDP):** хлебные крошки (Home › Sneakers › Nike › модель) ·
галерея · заголовок + colorway · выбор размера · **market data** (Last Sale,
изменение %, 52w min/max, **график цен**) · **Product Details** (Style=SKU,
Colorway, Retail Price, Release Date) · описание · Related Products ·
Recently Viewed.

**Сквозное:** у каждой сущности свой URL (можно делиться ссылкой), избранное
(«следить за моделью»), recently viewed, SEO-тайтлы.

## Аудит: чего не хватает нам (профессионально)

## План фаз

### Фаза 1 — Роутинг и постоянные ссылки (ФУНДАМЕНТ) — ✅ СДЕЛАНО
- react-router: `/`, `/catalog`, `/product/:id`, `/requests`, `/chats`,
  `/seller`, `/analytics`, `/profile`, `/admin`.
- Работают: кнопка назад/вперёд, F5 (остаёшься где был), «поделиться ссылкой
  на товар», deep links из чатов/уведомлений.
- `document.title` меняется по странице («Nike Air Force 1 — Search-app»).
- Бэкенд SPA-фолбэк уже готов (setNotFoundHandler → index.html).

### Фаза 2 — Глобальный хедер как StockX — ✅ СДЕЛАНО
- Поиск по центру хедера на всех страницах; при вводе — живые подсказки
  (топ-5 моделей: фото-мини + имя + мин. цена; Enter → каталог).
- Категории в хедере: Кроссовки · Одежда · Аксессуары · Коллекционное;
  пункт «Бренды» с выпадающим списком топ-брендов → каталог с фильтром.
- Строка трендов под хедером (топ-запросы из аналитики спроса) — тап = поиск.
- Мобайл: поиск-иконка разворачивается в строку; категории в каталоге.

### Фаза 3 — Паспорт модели (данные для PDP) — ✅ СДЕЛАНО
- Схема: `Model += colorway, retailPrice, releaseYear, description`
  (+ миграция `model_passport`). releaseYear вместо releaseDate: наша модель =
  силуэт, у силуэта нет одной даты релиза расцветки (см. DECISIONS).
- PDP: блок **«Детали товара»** — Артикул · Расцветка · Ритейл-цена · Год
  релиза + абзац описания; colorway под заголовком.
- Сид: паспорт для ~60 флагманских моделей (только проверенные факты;
  retailPrice сид не трогает — вводит админ).
- Бейдж «−N% от ритейла» на карточке каталога и на PDP, если мин. цена ниже
  retailPrice. Админ-редактор расширен: расцветка/год/ритейл/описание.

### Фаза 4 — PDP: полный StockX-вид — ✅ СДЕЛАНО
- Хлебные крошки: ← назад · Главная › Категория › Бренд › Модель (кликабельно:
  категория → каталог `?cat=`, бренд → каталог `?brand=&bn=`).
- **График цен** по завершённым сделкам (лёгкий SVG, без библиотек):
  сетка мин/мид/макс, даты, тултипы точек + «мин/макс за всё время»;
  при <3 сделках — честное «мало данных», при 0 — секция скрыта.
- «Похожие модели» — карусель (живые офферы того же бренда/категории,
  бренд в приоритете).
- Recently viewed (localStorage, 12 id) — ряд «Недавно смотрели» внизу PDP;
  батч-режим `/api/catalog?ids=` (пригодится главной).

### Фаза 5 — Каталог-браузер — ✅ СДЕЛАНО
- Десктоп: левый sticky-сайдбар фильтров — категории-дерево, бренды
  (мультивыбор, поиск по списку, счётчики офферов), размер, цена от/до,
  состояние; активные фильтры-чипы сверху с «сбросить всё».
- Мобайл: кнопка «Фильтры · N» → bottom sheet с живым счётчиком «Показать N».
- Фильтры размера/цены/состояния применяются к ОФФЕРАМ: мин. цена и счётчик
  карточки пересчитываются по подходящим предложениям.
- Пагинация «Показать ещё» (offset, страница 24) + total в ответе.
- Страница бренда `/brand/:id`: шапка (счётчики наличия) + его каталог
  (поиск внутри бренда); меню «Бренды» и крошка PDP ведут сюда.

### Фаза 6 — Главная как StockX — ✅ СДЕЛАНО
- `GET /api/home` — все ряды одним запросом: «Тренды недели» (поиски 7д,
  фолбэк — топ офферов), «Новые поступления» (свежий живой оффер), «Дефицит»
  (спрос 14д: поиски+запросы «Ищу» > живого предложения), «Обувь», «Одежда».
- Ряды-карусели с «Смотреть все →» (каталог с нужным фильтром/сортировкой;
  у дефицита — «Аналитика спроса»); `?sort=` в URL каталога.
- Плитки топ-брендов (буква+имя+офферы → `/brand/:id`).
- Hero-промо слот (задел под платное промо; пока — самопромо для продавцов).

### Фаза 7 — Вовлечение
- «Слежу» (избранное на модель): сердечко на карточке/PDP, раздел в профиле;
  фундамент под уведомления «появился оффер по твоей модели/цене».
- Recently viewed на главной.
- (открывает дорогу к пуш/email-уведомлениям и монетизации PRO)
