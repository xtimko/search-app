## Как запустить (ручная проверка)

```bash
npm install            # один раз, ставит оба воркспейса
npm run dev:backend    # терминал 1 → http://localhost:3000/health
npm run dev:frontend   # терминал 2 → http://localhost:5173 (страница «СтокПоиск»)
npm run db:studio      # (опц.) просмотр таблиц БД в браузере
npm run db:seed        # (один раз) залить стартовый справочник брендов/моделей
curl localhost:3000/api/brands?q=jor   # проверка автоподстановки
```

Фронт через dev-прокси сам дёргает `/health` и показывает «бэкенд: ok».
БД: нужен `.env` в корне с `DATABASE_URL` (локальный PostgreSQL). Миграции применены, таблицы созданы.
