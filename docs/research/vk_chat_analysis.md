# Анализ реального чата запросов (VK «BLUE SEARCH»)

> Источник: экспорт одного из главных текущих чатов, **43 307 сообщений** (запросы «Ищу …»).
> Агрегированные данные, без персональной информации. Дата анализа: 2026-06-28.
> Сырой дамп НЕ хранится в репозитории (только в temp при анализе).

## Главные выводы

1. **Сложился де-факто стандарт структурированного запроса** — покупатели уже думают нашими полями:
   `Бренд / Модель / Цвет / Размер / Состояние / Город / Примерка / Артикул`.
   44% сообщений — строго по этому шаблону, 55% — свободный текст, 97% начинаются с «Ищу».
   → Форма продавца и фильтры поиска должны повторять ровно эти поля.

2. **Размеры: US — основной, EU — второй, RU практически не используется.**
   US 53%, EU/EUR 40%, **RU 0%** (58 сообщений), см 2%. Половинные (8.5) — 16%, диапазоны (10‑10.5) — 13%.
   → В схеме держать US + EU; **RU из размеров можно убрать**. Обязательно поддержать половинные и диапазоны.

3. **«Примерка» — огромный фактор: 47% запросов.** Рынок офлайн-примерки в Москве.
   → Кандидат на отдельный атрибут листинга «примерка: да/нет».

4. **Гео сильно московское:** Москва 80%, «Вся РФ» 14%, СПб 1%. Остальные города — единицы.

5. **Рынок — почти весь НОВОЕ.** «новые» 23%, «б/у» — 58 сообщений (~0%). Коробка упоминается в 3%.
   → Дефолт состояния `new` верен; б/у — редкий кейс.

6. **Чат шире, чем кроссовки:** есть одежда (худи Supreme, куртки/пуховики, овершот C.P. Company),
   часы (AP × Swatch), сумки/ремни (Hermes), игрушки (Labubu). Продуктовый вопрос: остаёмся ли sneaker-only.

## Сленг и сокращения (для алиасов справочника)

- `NB` / `нб` → New Balance; `AF1` / `аф1` / «форсы» → Air Force 1; `TN` / «тн» → Air Max Plus;
  `дж` / «джордан» / `AJ1` → Jordan; «изи» → Yeezy; «адик» → Adidas; `TNF` → The North Face; «стоник» → Stone Island.
- Часто пишут **артикул вместо названия**: `M2002RDA`, `1906D` (15% запросов содержат «Артикул:»).
- Поиск идёт по **расцветке**: Mocha, Reverse Mocha, Onyx, "Protection Pack Harbor Grey" — цвет важен наравне с моделью.

## Рекомендации (вход для будущих фаз)

**Seed справочника** — пересобрать под спрос:
- Nike: Dunk Low/High, Air Force 1, Air Max 90/95/97/Plus(TN)
- Jordan: 1 Low/Mid/High, 4, 3, 11 (+ Travis Scott коллабы)
- New Balance: 2002R, 1906R/1906D, 990 v3–v6, 9060, 550, 530, 327
- Adidas: Samba, Gazelle, Campus, Yeezy 350/700/Slide/Foam Runner
- UGG: Tazz, Classic Mini; Asics: Gel-Kayano 14, Gel-1130, Gel-NYC; Salomon XT-6; Crocs
- (Puma/Reebok/Converse/Vans оставить, но низкий приоритет)

**Схема (рано и дёшево поправить сейчас):**
- Убрать `sizeRu` (не используется); оставить `sizeUs` + `sizeEu`, строки (поддержать «8.5», диапазоны).
- Добавить **алиасы/синонимы** бренду и модели (поле-массив или таблица) — решает «разнобой в написании» из ТЗ.
- Рассмотреть **`colorway`** (расцветка) у листинга и **`fitting`/«примерка»** (bool) у листинга.
- Псевдо-бренд/тег **Travis Scott** для коллабов.

**Парсер поисковой строки** (свободный ввод «Jordan 4 42»):
1. Срезать «Ищу/Куплю».
2. Выделить размер: `\d{1,2}([.,]5)?\s*(us|eu|eur|см)`, диапазоны и половинные; без юнита и число 35–48 → считать EU, 4–15 → US (уточнить).
3. Остаток матчить по алиасам бренда + названию/артикулу модели (contains/фуzzy), коллабы — отдельно.
4. Цвет и условия (новые/примерка/город) — вторичные фильтры.
